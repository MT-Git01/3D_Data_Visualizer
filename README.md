# 3D Data Visualizer

アップロードされたCSVファイルから3Dデータを読み込み、多様な3Dプロット（点群、線、スプライン、コンター、サーフェス）をインタラクティブに生成・操作・エクスポートするためのWebアプリケーションです。

---

## 1. 主な機能と特徴

* **CSVデータインポート & 自動解析:**
  * 3列または4列のCSVデータに対応。
  * 1行目のヘッダー自動判定（数値以外の文字列がある場合は列ラベルとして自動採用、無い場合はデフォルトで `X`, `Y`, `Z`, `Value` を割り当て）。
* **5つのインタラクティブ描画モード:**
  1. **点群 (3D Scatter):** 3D空間上の点群表示。
  2. **点と点の間を線で繋ぐ (3D Line):** 各点をCSVの行順に従って直線で接続。
  3. **点と点の間をスプライン曲線で繋ぐ (3D Spline Line):** SciPyを用いて滑らかな3Dスプライン曲線で補間（4列データ時はカラーグラデーションが適用されます）。
  4. **点群表示＋カラー (Contour Scatter):** 第4列のスカラー値に応じた点の色変化（コンター）。
  5. **サーフェス表示＋コンター (3D Surface Contour):** 点群データをベースに `griddata` 補間を施して空間上の表面メッシュを生成し、第4列の値に応じたグラデーションを描画。
* **プレミアムUI/UX (高い視認性と洗練されたデザイン):**
  * ダークモードとグラスモーフィズムを取り入れた洗練されたスタイリング。
  * サイドバーの背景色と文字色の最適化（ダークな背景に対してもすべてのラベルやテキストが読みやすいライトグレーに統一）。
  * ファイルアップローダー領域のダークテーマ化（ドラッグ＆ドロップ領域を暗色背景・白色テキストに統一し、高いコントラストを確保）。
  * グラフの3D回転、拡大・縮小、パン（平行移動）の標準サポート。
  * 点サイズ、軸ラベルのフォントサイズ、およびコンターのカラーレンジ（カラーバー対応）をサイドバーで自由にリアルタイム変更可能。
  * **「🔴 アプリを終了する」ボタン:** サイドバー最下部から、実行中のサーバープロセス（Python）を安全にワンクリックでシャットダウン可能。
* **100%視点連動・高画質ネイティブエクスポート:**
  * グラフの右上（ホバー時）に常時表示されるツールバー（Modebar）から、**現在ブラウザ上で見えている角度・拡大率のまま**、100%確実にプロットをPNG画像としてエクスポート可能。
  * 出力設定をカスタマイズし、一般的なキャプチャよりも大幅に鮮明な**高解像度（1350×900 / スケール2倍）の高品質PNG**として即座にローカルへ自動保存されます。
  * ツールバー自体もアプリのダークテーマに合わせてスタイリッシュにカスタマイズされています。
* **ワンクリック・デモ機能:**
  * 面倒なデータ準備なしに、検証用の3列（ローレンツ・アトラクタ）および4列（減衰波紋面）の美しいサンプルデータをワンクリックで読み込み可能。

## 2. システム要件 & 依存ライブラリ

* **Python バージョン:** Python 3.10+
* **主要ライブラリ:**
  * `streamlit` (UI構築)
  * `pandas` (CSVデータの読み込み・操作)
  * `numpy` (数値計算)
  * `scipy` (スプライン曲線補間および不規則格子サーフェス生成)
  * `plotly` (インタラクティブ3D描画および高画質エクスポートエンジン)

## 4. アプリケーションの起動と使用方法

### Step 1: 検証用サンプルの生成 (初回のみ)
あらかじめ描画検証を行うための3列、4列のCSVデータ（サンプル）を生成します。すでに生成されている場合は実行不要です。
```bash
python3 generate_sample_data.py
```
これにより、以下のファイルが生成されます：
* `lorenz_attractor_3d.csv`（ローレンツ・アトラクタの点群データ）
* `ripple_wave_4d.csv`（減衰波紋面のサーフェスデータ）

### Step 2: Streamlitサーバーの起動
Streamlit アプリケーションを起動します。
```bash
streamlit run app.py
```

### Step 3: ブラウザでの確認とエクスポート
起動後、ターミナルに表示されるURL（通常は `http://localhost:8501`）へブラウザでアクセスしてください。

1. **デモデータでの確認:**
   左側サイドバーの「またはサンプルデータを選択」から「ローレンツ (3列)」または「減衰波紋面 (4列)」を選択すると、即座に3Dプロットが表示されます。
2. **カスタムデータのインポート:**
   サイドバー上部のファイルアップローダーからお手持ちのCSVファイルをドラッグ＆ドロップまたは選択して読み込ませます。
3. **パラメータ調整:**
   点サイズや軸ラベルサイズ、コンターレンジの範囲をスライダーで変更すると、リアルタイムにグラフに反映されます。
4. **完璧なアングルでの高画質エクスポート:**
   3Dグラフ上をマウスでドラッグして回転させたり、スクロールでズームイン/ズームアウトし、お好みの視点（カメラアングル）に調整します。
   その後、グラフの右上（マウスをグラフ上にホバーさせると表示されるメニューバー）のカメラ型アイコン（`Download plot as a png`）をクリックすると、画面で見えているアングルのまま、高解像度の美しいPNG画像がダウンロードされます。
